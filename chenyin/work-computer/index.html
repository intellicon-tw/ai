律師工作電腦｜約 10 分鐘

第一次連線小瀛，
照著做就好。

這不是公司主機設定。你不需要操作 Mac mini、不需要 SSH，也不需要知道伺服器位置。

需要準備自己的工作電腦
登入帳號自己的 ChatGPT
向管理員取得個人 MCP URL
個人 MCP URL 等同密碼只貼到 ChatGPT 的 MCP endpoint 欄位。不要貼到對話、LINE、Telegram、Email、Notion、簡報、截圖或問題回報。

第一部分｜先向管理員取得個人連線

1

確認是你自己的個人 URL

每位律師使用自己的連線。若管理員尚未交付，請先停止，不要借用同事的網址。

完成：你已透過一對一安全管道收到完整個人 MCP URL。

第二部分｜在 ChatGPT 建立私人小瀛 App

2

登入 ChatGPT

在工作電腦開啟 chatgpt.com，登入自己的工作帳號。

3

打開 Apps 進階設定

依序進入 Settings／設定 → Apps → Advanced settings。若是 Business 工作區，也可能位於 Workspace settings → Apps → Create。

4

開啟 Developer mode

開啟 Developer mode。完全看不到此選項時，請找 ChatGPT 工作區管理員確認方案或權限。

5

建立私人 App

選擇 Create app／建立 App 或 Create custom MCP connector，名稱填「誠瀛法務小幫手（小瀛）」。

6

貼上完整個人 MCP URL

將管理員交付的完整網址貼到 MCP endpoint。不要刪字、不要拆出金鑰，也不要在前後加空格。

Authentication 選 No authentication個人識別已包含在完整 URL，不需要另外填 API key、Bearer Token 或 OAuth。
7

掃描工具並保持私人

按 Scan tools，確認出現 ask_chenyin，再按 Create。保留為自己的 Draft／私人 App，不要發布給整個工作區。

完成：Apps／Tools 選單看得到「誠瀛法務小幫手（小瀛）」和 ask_chenyin。

第三部分｜做第一次安全測試

8

開新對話並選擇小瀛 App

不要直接沿用舊對話。建立新對話後，從 Apps／Tools 選擇「誠瀛法務小幫手（小瀛）」。

9

送出這句測試指令

請使用誠瀛法務小幫手的 ask_chenyin，列出你能協助我的法律工作類型，以及我交辦時應提供哪些資料。這次不要處理真實案件。
10

確認真的呼叫小瀛

要同時看到「ChatGPT 實際呼叫 ask_chenyin」以及「小瀛回覆內容」。只有文字答案、沒有工具呼叫，不算完成。

若 ChatGPT 自己回答補一句：「請使用 ask_chenyin 交給小瀛處理。」
驗收完成：畫面出現 ask_chenyin 工具呼叫，並收到小瀛回答。

三個安全原則

  • 不共用同事的個人 MCP URL。
  • 不把個人 MCP URL 放進任何對話或文件。
  • 若網址疑似外洩，立刻請管理員停用並重發。
