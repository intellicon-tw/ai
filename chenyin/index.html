您說需求，小瀛負責分工。

小瀛是事務所的內部 AI 法務團隊主管。它會判斷需求、分派專職助理，再彙整成一份可供您覆核的草稿。

先記住這件事 所有產出都是內部協作草稿，並非正式法律意見。法源、事實、期限與對外文件仍須由承辦律師查核及放行。

下指令不必學術語，說清楚四件事

1. 背景與目的

2. 已知資料

3. 希望的成果

02｜Personal Agent

讓 Agent 讀取自己的 Email 與行事曆。

採個人綁定、唯讀優先。每位律師只授權自己的 Google 工作帳號，並在一對一 Telegram 私訊完成。

公司先準備

建立 Composio 環境與個人 Agent 身分。

律師完成授權

連接自己的 Gmail 與 Google Calendar。

核對後測試

確認沒有讀到他人資料，也沒有寫入或寄送。

律師｜約 5 分鐘

完成 Gmail／Calendar 授權

  1. 開啟管理員指定的小瀛 Telegram 一對一私訊。
  2. 輸入 /connect gmail，用自己的 Google 工作帳號完成授權。
  3. 回到 Telegram，輸入 /connect calendar，使用同一帳號完成授權。
  4. 輸入 /connections，確認兩項狀態。
  5. 待公司代表通知完成綁定後，測試 Email 摘要與行事曆空檔。
不要在群組操作不要傳送 Google 密碼、驗證碼、授權連結或畫面給任何人。
開啟 Telegram 測試 Bot

公司代表｜首次建置

建立 Composio 環境

  1. 用公司管理 Email 建立 Composio 帳號與 Project。
  2. 建立 API key，交由智慧方案以安全方式放入主機 secrets。
  3. 啟用 Gmail 與 Google Calendar，先採唯讀權限。
  4. 整理測試律師的公司 Email 與已確認 Telegram 帳號。
  5. 先由一至兩位律師完成授權，再核對與綁定。
  6. 驗證律師 A 無法讀取律師 B 的資料。
API key 不進對話不得貼入 LINE、Telegram、Notion、Email、Prompt 或一般 log。

綁定完成後，這樣測試

請列出我今天未讀信中需要處理的事項，不要寄出任何信件。
請告訴我明天下午的忙碌時段與一小時空檔，不要修改任何行程。
完成標準兩項結果正確、沒有看到其他人的資料，而且 Agent 沒有寄信或修改行程。

03｜進階連線

也可以在 Claude 或 ChatGPT 呼叫小瀛。

這一步需要管理員交付「屬於您自己的完整 MCP URL」。它等同個人密碼，不得分享、截圖或貼進普通聊天。

Claude

  1. 開啟 Settings → Connectors。
  2. 選擇 Add custom connector。
  3. 名稱填「誠瀛法務小幫手（小瀛）」。
  4. 貼上完整個人 MCP URL，不另外填 OAuth 或 API key。
  5. 在新對話啟用 Connector，確認工具清單有 ask_chenyin。

ChatGPT

  1. 使用網頁版，進入 Settings → Apps → Advanced settings。
  2. 啟用 Developer mode，建立 Custom MCP App。
  3. 貼上完整個人 MCP URL，驗證選 No authentication。
  4. Scan tools，確認有 ask_chenyin 後建立。
  5. 保持私人 Draft，不發布到整個工作區。
請使用誠瀛法務小幫手的 ask_chenyin，列出你能協助我的法律工作類型，以及我交辦時應提供哪些資料。這次不要處理真實案件。

04｜問題排除

看到錯誤時，先判斷是哪一層。

畫面或症狀代表什麼怎麼處理
看不到 Connector／Developer mode帳號方案或工作區權限尚未開放請工作區管理員確認；暫時改用 LINE 或 Telegram。
找不到 ask_chenyin工具尚未啟用、URL 不完整或掃描未刷新在新對話重新啟用或 Scan tools；不要公開貼出 URL。
401／Unauthorized個人 URL 貼錯、失效或已停用停止重試，請管理員檢查或換發。
530／1033／Unable to connect服務端或 Tunnel 暫時離線保留設定，回報發生時間與遮蔽金鑰的畫面。
選錯 Google 帳號授權身分不正確立刻停止測試、撤銷第三方存取權，再用正確帳號重做。
回報問題時只提供發生時間與症狀。截圖前遮住個人 MCP URL、key= 後方內容、OAuth 連結與任何驗證資訊。
