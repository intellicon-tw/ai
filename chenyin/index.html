瀛誠瀛律師 AI Agent 指南三步驟目錄
第一次啟用｜照順序操作

第一次使用小瀛，
只要完成 3 個步驟。

先讓 Mac mini 上線，再用工作電腦設定 ChatGPT MCP，最後實際呼叫小瀛。請依順序完成，不需要先理解技術名詞。

開始前準備Mac mini、螢幕、鍵盤滑鼠、Wi‑Fi 資料、工作用電腦、ChatGPT 帳號，以及管理員交付的個人 MCP URL。
步驟 1｜主機上線

Mac mini 插電、開機、確認能上網

  • 接上電源與螢幕
  • 按下電源鍵開機
  • 確認 Wi‑Fi 已連線
  • 用瀏覽器實際開啟網站
完成：Mac mini 可以正常上網。
打開步驟 1 教學
步驟 2｜工作電腦設定

開啟 ChatGPT，加入個人 MCP

  • 登入 ChatGPT 網頁版
  • 進入 Apps／Developer mode
  • 建立私人 MCP App
  • 確認看得到 ask_chenyin
完成：ChatGPT 顯示小瀛工具。
打開步驟 2 教學
步驟 3｜第一次測試

在 ChatGPT 實際呼叫小瀛

  • 開啟新對話
  • 選取小瀛 App
  • 送出安全測試指令
  • 確認有呼叫工具並收到回答
完成：小瀛成功回覆測試問題。
打開步驟 3 教學
三步都完成了代表主機、ChatGPT 與小瀛已連通。接下來可先用不含真實案件資料的問題練習，再逐步交辦工作。
