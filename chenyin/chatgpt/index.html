步驟 2｜工作電腦設定

在 ChatGPT 加入小瀛 MCP

請在平常工作的電腦操作。需要管理員交付的「完整個人 MCP URL」，它等同個人金鑰。

1｜Mac mini 上線必須已完成
2｜ChatGPT 設定目前所在步驟
個人 MCP URL 等同密碼只貼到 ChatGPT 的 MCP endpoint 欄位。不要貼到普通聊天、LINE、Telegram、Email、Notion、簡報、截圖或問題回報。
1

打開 ChatGPT 網頁版

在工作用電腦開啟 chatgpt.com，登入自己的工作帳號。

看到：ChatGPT 對話首頁。
2

進入 Apps 進階設定

打開 Settings／設定 → Apps → Advanced settings。Business 工作區也可能要從 Workspace settings → Apps → Create 進入。

看到：Developer mode 或建立自訂 MCP App 的選項。
3

啟用 Developer mode

開啟 Developer mode。若完全看不到此選項，代表目前帳號方案或工作區權限尚未開放，請找管理員處理。

4

建立新的私人 App

選擇 Create app／建立 App 或 Create custom MCP connector。名稱填入「誠瀛法務小幫手（小瀛）」。

5

貼上完整個人 MCP URL

把管理員交付的完整網址貼到 MCP endpoint。不要刪掉網址中的任何內容，也不要在前後加空格。

不要拆出金鑰不要把 URL 裡的個人識別資料改貼到 API Key、Bearer Token 或其他欄位。
6

驗證方式選 No authentication

個人識別已包含在完整 URL 中，不需要另外設定 OAuth、API key 或 Bearer Token。

7

掃描工具

按 Scan tools，等待 ChatGPT 讀取工具清單。

看到：工具清單出現 ask_chenyin。
8

建立並保持私人使用

按 Create 完成。保留為自己的 Draft／私人 App，不要發布到整個工作區，因為它使用您的個人 MCP URL。

完成：在新對話的 Apps／Tools 選單可以選到「誠瀛法務小幫手（小瀛）」。
步驟 2 完成標準ChatGPT 已建立私人小瀛 App，並能看到 ask_chenyin 工具。
