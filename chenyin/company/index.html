步驟 1｜公司先完成

公司代表建立 Composio 環境

先把公司環境、唯讀權限與測試入口準備好，再通知律師進行個人授權。

1｜公司代表設定目前所在步驟
2｜律師個人授權公司確認就緒後才開始
操作原則公司代表照下面 8 步操作即可。需要技術設定時請智慧方案協助，不必自行寫程式。
開啟 Composio DashboardComposio 官方文件
1

建立 Composio 帳號

使用公司管理用 Email 註冊並完成驗證，指定一位主要管理員與一位備援管理員。

完成：可以正常登入 Dashboard。
2

建立 Project

在 Dashboard 建立 Project，名稱建議使用「公司名稱－Personal Agent」。測試環境與正式環境分開。

完成：Dashboard 顯示新的 Project。
3

建立 API key

在 Project 設定建立 API key，交由智慧方案以安全方式放入主機 secrets。

API key 不進對話不可貼入 LINE、Telegram、Notion、Email、Prompt 或一般 log。
4

設定 Gmail 與 Calendar

請智慧方案建立 Gmail 與 Google Calendar 連線，第一階段只開放讀取，不開放寄信、刪信、新增或修改行程。

完成：兩個服務都能產生 HTTPS 授權連結。
5

準備第一批測試名單

整理律師姓名、公司 Email 與已確認的 Telegram 帳號。先選一至兩位測試，不要一次開放所有人。

完成：每位測試律師都有獨立 Personal Agent 身分。
6

測試 Telegram 入口

在一對一私訊依序測試 /connect、/connect gmail、/connect calendar、/connections。

完成：私訊能取得連結，群組不會出現私人授權連結。
7

通知律師完成授權

確認前六步完成後，再把律師授權子頁傳給測試律師。請律師回報 Gmail 與 Calendar 的狀態。

開啟律師授權子頁
8

核對、綁定與驗收

核對 Telegram 使用者與 Google 工作帳號、綁定到正確 Personal Agent，並測試律師 A 無法讀取律師 B 的資料。

完成：正確帳號已綁定、唯讀測試通過、不同律師資料不會混用。
可以通知律師的時點Composio、Gmail、Calendar、Telegram 入口與第一位測試者身分都準備完成後，才通知律師開始步驟 2。
