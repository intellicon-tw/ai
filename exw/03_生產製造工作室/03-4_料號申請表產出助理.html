① 需求與痛點

開發課要新建料號時，得先人工翻 ERP 確認有沒有重複，再照編碼規則一碼一碼湊料號、手打申請表，容易建出重號或編錯碼，事後在 ERP 清理很痛。

② 開發思路

  • 先比對再新建是防止 ERP 料號爆量的關鍵，所以流程強制第一步查廠內料號對照表，完全相同就直接回既有料號、不再新建。
  • 編碼規則放全文查找知識庫、逐碼拆解說明輸出，讓 Agent 依規則組號而非憑記憶，主管審核時也能看到每一碼的依據。
  • 高度相似（僅顏色或長度不同）也要列出供參考，幫開發課判斷是沿用相似料號改規格、還是真的要新建。
  • 申請表把成本估算與申請人留空、附建議簽核流程，符合『Agent 產草稿、人做決策簽核』的分工，非標準色/特殊要求則於表中註明 MOQ 與需開模具。

# 角色
您是卓新工業開發課的料號管理助理，熟悉卓新料號編碼規則（例如 6ASSWHB50010 代表 Cat.6A / S/STP / White housing / B 型模具 / 5M / 10 種變體）。

# 任務
當業務或開發人員描述新產品規格時，先查 ERP 是否已有對應料號，若無則依料號編碼規則產出料號申請表，供主管簽核後於 ERP 建立新料號。

# 背景知識
請查詢：
1. 「廠內料號對照表」（表格查詢知識庫）：現有所有料號與規格。
2. 「料號編碼規則」（全文查找知識庫）：每一碼位的規則定義（類別、屏蔽、顏色、外殼、長度、變體等）。

# 輸入格式
使用者以自然語言描述新產品規格，至少包含：
- 產品類別（Patch Cord / Keystone Jack / RJ45 Plug 等）
- 規格（類別 Cat.5e/6/6A/8、UTP / STP、AWG、長度）
- 外觀（顏色、扁線 / 圓線、是否 Snagless）
- 客戶是否有特殊要求

# 執行流程
1. 根據使用者描述，組出初步規格摘要。
2. 查詢「廠內料號對照表」，比對是否已有相同或高度相似料號：
   - 若完全相同 → 回覆既有料號，無需新建
   - 若高度相似（僅顏色或長度不同） → 列出相似料號供參考
3. 若確認需新建，查詢「料號編碼規則」，依規則逐碼產出料號。
4. 組合完整料號申請表內容：新料號、品名、規格、成本估算欄（留空）、申請人（留空）、建議簽核流程。

# 輸出格式
輸出三個區塊：

## 一、ERP 既有料號比對
列出找到的相同或高度相似料號（若無則寫「ERP 中無相同或高度相似料號，建議新建」）。

## 二、新料號建議（若需新建）
逐碼拆解說明（例如：第 1-2 碼 6A = Cat.6A；第 3-4 碼 SS = S/STP...）。

## 三、料號申請表草稿
結構化欄位，可直接填入公司制式申請表。

一、料號結構總覽
料號由「前綴識別碼」＋「數字規格尾碼」組成：

  [1-2 類別等級][3-4 屏蔽結構][5-6 顏色][7 外殼/模具型號][8以後 規格長度變體數字碼]

範例：6A SS WH B 50010
  → Cat.6A / S/STP / 白 / B型模具 / 尾碼 50010

============================================================
二、逐碼位定義

第 1-2 碼｜類別等級
  6A = Cat.6A
  C6 = Cat.6
  C5 = Cat.5e
  C8 = Cat.8

第 3-4 碼｜屏蔽結構
  UT = UTP（無屏蔽）
  FT = FTP（整體鋁箔）
  SS = S/STP（每對鋁箔＋整體編織）
  SF = S/FTP（每對鋁箔＋整體編織，資料中心高階）

第 5-6 碼｜顏色（護套/外殼）
  WH = 白    BK = 黑    BL = 藍    RD = 紅    GN = 綠
  YL = 黃    GY = 灰    OR = 橘    PL = 紫    PK = 粉紅（非標準色）

第 7 碼｜外殼/模具型號
  A = A 型模具（標準護套）
  B = B 型模具（Snagless / 加強防勾）

第 8 碼以後｜數字規格尾碼
  由 AWG、外型、長度與變體流水碼組成，實際配號以 ERP 對照表為準（示範用）。
  常見對照：
   - 長度碼：1=1M、2=2M、3=3M、5=5M、7=7M
   - 外型：圓線標準不另標；Slim 以 153 段標記、Flat 以 138 段標記（示範）
   - 末四碼為變體/流水碼（如 0010 = 第 10 號變體）

⑤ 建置流程與上線重點

正式上線前的準備指南
一、知識庫資料準備：以 ERP 匯出完整「廠內料號對照表」（料號、品名、Cat 等級、屏蔽、AWG、外型、長度、顏色、外殼型號、狀態）作表格查詢；將開發課料號編碼手冊整理為「料號編碼規則」全文查找知識庫，逐碼位定義與顏色/屏蔽代碼要完整。
二、資料正確性：料號對照表需含停產/淘汰狀態，避免比對到不該再用的料號；編碼規則的數字尾碼對照請以 ERP 實際配號邏輯為準，範例中的尾碼規則僅供教學。
三、平台設定：模型 Claude 4.6 Sonnet；執行模式單階段；掛入廠內料號對照表（表格查詢）與料號編碼規則（全文查找）；本題不需外部工具。
四、驗測與調校：用既有料號查詢與需新建料號各測一次，確認相同料號不會被重建、新建料號逐碼有依據且不與既有衝突；觀察高度相似料號是否正確列出。
五、上線後維運：新料號核准建檔後即時更新對照表，維持比對準確；編碼規則調整時同步更新；蒐集開發課回饋，補充常見規格的組號範例。

⑥ 驗測情境（測試資料＋預期結果）

展開完整驗測情境
情境1（既有料號直接回覆）
input：「客戶要 Cat.6A UTP 26AWG 1M 白色 Patch Cord，我們 ERP 有沒有料號？」
expected：於廠內料號對照表找到 6AUTWHA102B50010，回覆使用既有料號即可、無需新建。
驗證重點：不會重複建立已存在的料號，節省開發課工作。

情境2（新料號建議／需新建）
input：「客戶要 Cat.6A S/FTP 26AWG 7M 粉紅色 Patch Cord，外殼要紅色，這個 ERP 應該沒有，幫我開申請表。」
expected：比對後判定無相同/高度相似料號，依編碼規則逐碼產出新料號並拆解說明（6A=Cat.6A、SF=S/FTP、顏色/外殼、長度、變體），產出料號申請表草稿；註明粉紅為非標準色、需開模具與 MOQ。
驗證重點：料號編碼各碼位都有對應解釋；新料號不與既有料號衝突；成本估算與申請人欄留空供人工填寫。
