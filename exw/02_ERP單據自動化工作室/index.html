部門講評：這一批「02 ERP單據自動化工作室」的需求盤點做得相當扎實，屬於可以直接進開發的題目。四隻 Agent 都圍繞卓新最痛的 ERP 抄打與核對環節——水單認款、採購核價、三角貿易轉檔、月結對帳，每一題都附了完整的七段式系統提示詞、清楚的知識庫欄位定義、測試資料集與驗測情境，尤其把「讀圖／PDF」與「查知識庫」用兩階段隔離開來，這一點抓得非常到位，代表現場同仁對流程真的很熟。要正式上線前，還需要卓新提供幾份真實資料：實際的應收帳款與客戶匯款別名（銀行水單上各種奇怪的英文抬頭）、大東等供應商的最新報價單、三角貿易轉檔的內部 SOP 與各客戶特殊備註、以及 ERP 匯出的國內銷貨明細。目前 kb/ 內的範例檔都是示範資料，換成真資料後即可進 POC 驗測。以下每一頁對應一個需求，點進去可看到：需求與痛點 → 開發思路 → 完整提示詞 → 知識庫設計 → 建置流程 → 驗測情境。

#02-1示範題

銀行水單辨識與收款單草稿助理

單據核對型（圖片辨識＋表格查詢比對）

會計每天要把客戶匯款的銀行水單一張張對到應收帳款，光是把水單上五花八門的英文匯款人名對回 ERP 客戶名、再找出對應發票就要翻半天，遇到金額差幾塊美金還得追是手續費還是匯差，一忙就容易對錯、認錯款。

 #02-2示範題

採購單 vs 廠商報價核對助理

單據核對型（表格查詢比對）

採購把 ERP 採購單的單價一項項 key 進去，一旦誤 key 或沿用舊報價，成本就默默吃掉利潤；現在要人工翻供應商最新報價單、確認有沒有過期、數量有沒有到 MOQ，項目一多就漏看，等到對帳才發現已經晚了。

 #02-3示範題

三角貿易出通單轉檔助理

文件生成型（向量知識庫問答＋轉檔）

三角貿易一筆單要從 2702 出通單手動抄成 2601 銷貨單、再轉 6401 結帳單，欄位哪些照抄、哪些要重算、匯率抓結匯日還是 B/L 日、發票要不要 Zero-rated，全靠業務記在腦袋裡，一忙就抄錯終端客戶或用錯匯率日，出錯還很難查。

 #02-4示範題

國內銷貨對帳單產出助理

文件生成型（表格查詢＋對帳單產出）

每月 25 日前業務要一家家客戶把當月出貨、退貨從 ERP 撈出來、逐筆貼成對帳單、再算淨應收、寫對帳 Email，一個客戶就要花大半天，月底一忙很容易把退貨算進出貨、金額加錯，客戶一對就退回來重做。
