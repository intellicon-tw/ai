會計與管理工作室 · 解題示範

共 4 款 Agent POC來源 卓新同仁需求盤點

這一批「會計與管理工作室」的四隻 Agent 盤點得相當扎實：每一題都附了完整的七段式提示詞、清楚的知識庫欄位定義，還有可以直接跑的測試資料與驗測情境，屬於 A 級、可以直接進入開發的品質。進貨單核單、費用月報、銷售機會、樣品追蹤，剛好把採購課、會計部到業務部每週最耗神、又最怕出錯的例行比對與追蹤都涵蓋進來了。要真正上線，還需要卓新補三樣真實資料：ERP 實際匯出的採購單與部門費用明細（確認欄名與科目代號一致）、會計部現行的月報表格式與費用科目對照、以及業務端目前在用的銷售機會與樣品追蹤表。把這些換成真資料、再跑過兩三輪驗測校準，就能正式服役。以下每一頁對應一個需求，點進去可看到：需求與痛點 → 開發思路 → 完整提示詞 → 知識庫設計 → 建置流程 → 驗測情境。

#05-1示範題

進貨單核單助理

單據核對型（表格查詢比對）

採購課每天要把供應商 Invoice 逐項對回 ERP 採購單，人工比對品號、數量、單價、幣別，一張多品項的單子就要看好幾分鐘，遇到超量到貨或分批到貨很容易看漏，錯了就直接影響入帳與應付帳款。

 #05-2示範題

部門費用月報彙整助理

文件生成型（表格查詢對應）

每月結帳時，會計要把 ERP 匯出的一長串部門費用明細，一筆一筆對回月報表的科目列、再手動加總填格子，量大又重複，看久了容易填錯列、加錯總，月報一錯就要整張回頭抓。

 #05-3示範題

銷售機會追蹤彙整助理

提醒排程型（表格查詢＋時間判斷）

業務主管每週要盯十幾筆 pipeline，靠人工翻表看哪筆該追、哪筆逾期、哪筆卡在報價很久，很難每次都看全，常常等到客戶跑掉才發現某個案子已經停滯一個多月。

 #05-4示範題

樣品追蹤提醒助理

提醒排程型（表格查詢＋Email 生成）

樣品寄出後常常就斷了線：業務忙起來忘了確認送達、忘了追客戶 Feedback，樣品送到客戶手上卻沒下文，白白錯過轉單時機，也沒人記得該在哪個時間點催覆。
