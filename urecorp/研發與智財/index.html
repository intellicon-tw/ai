研發與智財這兩題填得算是全部門裡數一數二清楚的：專利檢索與文獻摘要有明確場景（Google Patents、技術期刊）、有 KPI（降低人力負荷），可以直接開發。實驗數據分析那題方向也對，但「大數據樣本」到底多大沒有講——是幾百筆還是幾百萬筆，會直接決定要不要先做彙總前置，這是目前最需要補的資訊；另外兩題都還缺實際範例檔（過去的檢索結果、批次數據匯出檔），有這些才能把 Agent 調到貴部門真正的口味。以下每一頁對應一個需求，點進去可看到：需求與痛點 → 開發思路 → 完整提示詞 → 知識庫設計 → 建置流程 → 驗測情境。

#011A · 適合

專利檢索與技術文獻摘要助手

文獻檢索與摘要型

希望「透過AI，大幅減少人員進行專利檢索與分析的時間」，並「藉由AI快速歸納與整理技術期刊與文獻的重點」，降低人力負荷與提升工作績效。

 #012B · 部分適合

實驗數據統計與異常分析助手

資料彙整分析型

希望 AI 協助「資料收集與整合」「數據統計與異常分析」與「大數據樣本的交叉比對」，加速異常分析的處理速度、提昇工作效能，並確保蒐集資料的完整性及適用性、分析特性與表徵。
