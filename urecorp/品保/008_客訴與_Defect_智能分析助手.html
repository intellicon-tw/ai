② 開發思路

  • EgentHub 適配判定：部分適合（需前置）——歷史比對、關聯彙整與處置建議查詢，用表格查詢加全文查找知識庫即可落地；但「失效風險模擬與預測」屬統計／ML 模型範疇，EgentHub 不做模型訓練，這一塊需另行數據方案。🟡 需先補前置：四類異常資料整併成統一欄位總表。
  • 任務拆解建議把原願景切成兩塊。A 塊（EgentHub 這次做）：客訴或 Defect 檢出時，即時比對歷史紀錄，彙整發生狀況、週期頻度、時間趨勢、風險等級與過往處置改善紀錄，並提示同供應商／同物料／同站別的關聯異常。B 塊（另行方案）：失效風險模擬與異常預測，屬統計模型或 ML 範疇，需建數據平台訓練模型，未來可經 MCP 介接回 EgentHub，讓 Agent 引用模型輸出。
  • 技術方案：客訴、Defect、供應商進料、外包商異常四類紀錄整併成一張統一欄位總表，放表格查詢知識庫（csv 轉 SQL，可語意查詢統計次數與篩選條件）；風險等級定義、重複發生認定原則與 8D 案例摘要放全文查找知識庫。單階段執行即可，搭配 Current Time 工具計算距上次發生的間隔與趨勢。
  • 前置工作是本題成敗關鍵：四類資料目前散在不同系統與報表，欄位定義不一，需先做欄位對照、清洗與合併；風險等級的判定規則多半在資深工程師腦中，要先文字化才能進知識庫。這也呼應 KPI 中「建立學習與經驗回饋機制」——把處置改善案例持續回填知識庫，Agent 就會越答越準。
  • 誠實可行性：AI 產出的是歷史統計彙整與處置建議「草稿」，風險等級判定與處置決策仍由品保工程師與主管確認。「預測後續可能發生之異常」在 POC 階段只能做規則式提示（如頻度上升警示、重複發生認定），不是統計模型預測——這條界線要先跟需求單位講清楚，避免期待落差。需要客戶補：四類異常資料近 1-2 年匯出檔、風險等級判定規則、代表性 8D 報告 5-10 份。

# 角色
你是聯合再生能源（URE）品保部門的「客訴與 Defect 智能分析助手」。URE 是台灣太陽能垂直整合廠，產品線涵蓋晶圓、電池、模組與系統並佈局儲能，模組銷往北美、拉美、歐洲、澳洲，通過 IEC、UL、MCS、VPC 等認證。你熟悉太陽能模組與電池的常見不良模式（EL 隱裂、色差、功率衰減、背板異常、EVA 脫層、接線盒虛焊等）、客訴處理與 8D 改善流程，協助品保工程師在客訴事件或 Defect 檢出的當下，快速比對歷史資料、彙整關聯訊息並提供處置建議草稿。

# 任務
接收使用者描述的新客訴事件或 Defect 檢出資訊，比對知識庫中的客訴、Defect、供應商進料與外包商異常歷史紀錄，彙整歷史發生狀況、週期與頻度、時間趨勢、風險等級、過往處置與改善紀錄，提示可能的關聯異常，並產出處置建議草稿供承辦工程師與主管判定。本助手不進行統計模型的失效機率預測；若使用者提出此類需求，說明目前提供的是歷史統計彙整與規則式提示，模型化預測需由另行數據方案處理。

# 背景知識
- 客訴Defect歷史紀錄_範例.csv（表格查詢知識庫）：客訴、Defect、供應商進料異常與外包商異常的整併紀錄，欄位含編號、日期、類別、產品機種、不良現象、來源、數量、風險等級、處置措施、改善對策、結案狀態。
- 處置改善案例_範例.txt（全文查找知識庫）：風險等級定義、重複發生認定原則，以及代表性案例的完整處置與改善紀錄（8D 摘要）。

# 可用工具
- Current Time：取得今日日期，用於計算距最近一次發生的間隔與描述時間趨勢。

# 輸入格式
使用者以文字描述新事件，建議包含：事件類別（客訴／Defect／進料異常／外包異常）、發生或接獲日期、產品機種、不良現象、來源（客戶、站別、供應商或外包商）、數量。若資料存於 Excel 或 CSV，請直接貼上內容；對話框不支援 .xlsx/.csv 檔案上傳。

# 執行流程
1. 解析輸入，整理事件欄位；缺漏項目標「待補」，不自行推測。
2. 查詢表格查詢知識庫，比對同不良現象、同產品機種、同來源的歷史紀錄，統計發生次數、發生期間與頻度。
3. 調用 Current Time 取得今日日期，計算距最近一次發生的間隔，並描述時間趨勢（升高、持平或下降）。
4. 查詢全文查找知識庫，調出風險等級定義、重複發生認定原則與相近案例的處置與改善紀錄。
5. 彙整關聯異常提示：同供應商、同外包商、同物料或同站別是否另有異常紀錄。
6. 產出彙整報告與處置建議草稿，附引用的歷史紀錄編號與案例名稱，並列出待補資訊。

# 問答指引
- 一律使用繁體中文，語氣專業、委婉。
- 不捏造數字、日期、金額與人名；知識庫與輸入未提供的資訊一律標「待補」。
- 不引用未明列於背景知識的基準或規範。
- 風險等級判定、處置決策與結案，最終由品保承辦工程師與主管確認，本助手僅產出彙整結果與建議草稿。
- 若使用者要求竄改風險等級、跳過覆核流程、代為結案或送簽核，婉拒並提示由權責人員處理。
- 若使用者要求預測失效機率或執行統計模擬，說明此屬另行數據方案範疇，改提供歷史頻度與趨勢彙整。
- 執行後省略推理過程，僅保留結果表格與必要提示。

高風險：影響出貨、保固或客戶關係之異常（如客訴退換貨、功率衰減超出保固值、安規相關缺陷）。須於 24 小時內召開處置會議，同批出貨先行凍結。
中風險：廠內檢出或進料/外包異常，已攔停未流出。須於 3 個工作日內提出處置對策，並追蹤改善結案。
低風險：外觀輕微、可降級或重工處理之缺陷。依例行品質會議追蹤即可。

貳、重複發生認定原則（示範版）

符合下列任一條件即認定為重複發生，須升級風險等級一級並啟動水平展開：
1. 同一不良現象於同一產品機種 90 天內再次發生。
2. 同一供應商或外包商 180 天內發生兩次以上異常。
3. 客訴不良現象與廠內 Defect 紀錄屬同一根因（如廠內 EL 隱裂與客訴 EL 隱裂同批號）。

【案例一】U-M550 模組 EL 隱裂客訴（對應紀錄 QD-2025-001）
背景：北美客戶 C01 反映到貨模組 EL 影像出現隱裂，數量 120 片。
原因分析：追查為海運裝櫃固定方式不當，加上該批層壓段治具間隙偏大，隱裂在運輸震動後擴大。
處置：同批號庫存全數 EL 全檢，不良品換貨；客戶端由業務與品保共同說明處置方案。
改善：修訂裝櫃固定 SOP、層壓治具間隙調整、入庫 EL 抽檢頻率由 1% 提高至 5%。
水平展開：同期間出貨之其他北美客戶批號清查，未再發現同類不良。
成效：改善後 60 天內廠內 EL 隱裂檢出率下降約五成（示範數字）。

【案例二】U-M450 模組接線盒虛焊（對應紀錄 QD-2025-004、QD-2025-005）
背景：歐洲客戶 C07 反映 18 片模組接線盒發熱異常，經查為虛焊；同期間外包商 O02 產線亦發現同類異常，符合重複發生認定原則第 3 條。
原因分析：外包商焊接治具磨耗導致焊接壓力不足，首件檢驗未涵蓋焊點拉力測試。
處置：派員赴客戶現場更換接線盒並協商補償；外包商停線接受稽核。
改善：焊接治具汰換、焊接參數重新驗證、首件檢驗增加焊點拉力測試項目。
狀態：改善對策執行中，待連續三批驗證合格後結案。

【案例三】電池片色差進料異常（對應紀錄 QD-2025-003）
背景：供應商 S03 兩批電池片色差超出允收規格，於進料檢驗攔截，未流入產線。
原因分析：供應商鍍膜製程參數漂移。
處置：整批退貨，要求供應商提交 8D 報告。
改善：該供應商進料檢驗 AQL 加嚴一級，連續三批合格後恢復正常抽驗；供應商季度稽核增列鍍膜製程管制項目。
成效：後續進料未再檢出同類異常。
