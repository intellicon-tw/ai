製造本部這三題都圍繞「量測與規範」在打轉，方向抓得很準：FAI 首件檢驗報告草稿把每份 2-6 小時、每月 20-40 份的填表苦工交給 AI 先擬草稿並自動標超差，是最具體、最有感的亮點題；原廠規範比對與生產週報則分別補上「製程對客戶 spec 的缺口盤點」與「產線數據週報」，涵蓋了製造端從進料檢驗到產出彙整的主軸。要真正把這些 Agent 做出來，關鍵在補真實資料：FAI 題請提供實際的 AS9102 表格範本、ballooned drawing 對應的特性清單與一份去識別化量測報告匯出欄位；規範比對題最需要釐清 Boeing/GE/Airbus spec 的 OEM 授權範圍與可放入知識庫的章節，並附一份製程文件與特殊製程認證清單範例；週報題初期先給一份產線／品質數據的 Excel 匯出樣本（欄位、單位、達成率算法），中期再評估 MES 串接。這些補齊了，落地會很快。以下每一頁對應一個需求，點進去可看到：需求與痛點 → 開發思路 → 完整提示詞 → 知識庫設計 → 建置流程 → 驗測情境。

標準化作業
