任務盤點表轉化的 POC 解題示範（每題一頁，含完整開發思路與提示詞）

部門 補給本部（採購／庫管）共 4 款 Agent POC理念 人機協作 · 非全自動

補給本部這組盤點很扎實：四題全部落在採購與庫管每天真實會碰到的痛點——詢比報價彙整比價、適航文件（8130-3／EASA Form 1）核驗初審、替代件號互換性比對、庫存與交期預警解讀，場景具體、輸入輸出與處理邏輯都寫得清楚，而且優先順序高、量能明顯（比價每月上百案、收料核驗每月數百批），是最容易做出即戰力的一群。要把這幾隻 Agent 真正做出來，最該補的是「真實的樣本與授權範圍」：實際的供應商報價單與 Email 範本、8130-3／Form 1 掃描檔與件號主檔、歷史採購價格紀錄、以及 AMOS 庫存／在途／需求的匯出欄位；替代件號那題還需要確認 IPC 互換性資料的 OEM 授權範圍，只放授權內的摘錄。提醒一下適航紅線：這幾隻 Agent 只做擷取、比對、標異常與產草稿，最終允收、議價核決與放行判定仍由收料檢驗與採購授權人員負責。把上面這些真實資料補齊，就能從 B 升到可直接開發的 A。以下每一頁對應一個需求，點進去可看到：需求與痛點 → 開發思路 → 完整提示詞 → 知識庫設計 → 建置流程 → 驗測情境。

#12

詢比報價彙整比價表

審查比對

採購每案要人工翻閱多家 PDF／Email 報價、逐欄抄成比價表再回查歷史價，每案耗時 1-3 小時、每月 100-200 案，件況與件號易看錯、異常常漏抓。

 #13

適航文件核驗初審助手

審查比對

收料檢驗每批 8130-3／Form 1 逐欄核對件號序號與訂單一致性約需 20-40 分鐘，全公司每月 300-600 批，人工比對易漏看欄位與狀態不符。

 #14

替代件號互換性比對

審查比對

料件缺件或急件時，採購／航材規劃需逐筆翻 IPC、互換性紀錄與歷史採購領用資料找可用替代件號，每次 20-60 分鐘、每月 100-300 次，靠個人經驗且易漏掉單向互換或需改裝的限制。

 #15

庫存與交期預警解讀助手

數據解讀

庫管與採購主管每週要花 2-4 小時、每月 8-16 次人工比對 AMOS 庫存、在途與需求，才能找出缺料風險與長交期件，容易漏看造成停場（AOG）與臨時緊急採購。
