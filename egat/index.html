長榮航太 AI Agent 開發實務工作坊

由各部門任務盤點表轉化的 41 個 POC 解題示範（每題一頁）

共 15 個部門合計 41 款 Agent POC分級 A / B / C 反映盤點完整度

本站由智慧方案依航空 MRO 產業特性與長榮航太組織架構，將 15 個單位、41 個建議優先開發的 AI Agent 場景，逐一開發為可在 EgentHub 落地的完整 POC。每個部門依任務盤點的完整度分級：A 級場景具體、可直接開發；B 級主題清楚、關鍵資料或 OEM 授權／系統串接待補；C 級為產業推測候選。核心理念是「人機協作、非全自動」——AI 負責讀取、彙整、產草稿、標異常，最終判定與簽署永遠在授權持照人員。

A

A 級部門

場景具體，輸入／輸出／處理邏輯清楚，可直接開發

A 級4 題 POC

定修本部

技術文件問答、NRC 缺陷描述、工卡摘要、重複缺陷分析——高頻剛需、可直接開發

A 級4 題 POC

品保／品管部

法規問答、稽核清單、CAPA 草稿、稽核趨勢分析——文件型任務、資料結構清楚

A 級4 題 POC

補給本部（採購／庫管）

比價表、適航文件初審、件號互換、庫存預警——結構化表格查詢為主

A 級3 題 POC

電算部

Helpdesk 分流、AMOS FAQ、Log 與資安摘要——IT 內部任務、易快速見效

A 級3 題 POC

訓練部

教材題庫、檢定到期追蹤、招訓排程——流程明確、可直接落地

A 級3 題 POC

企劃室／業務

英文回覆、合約摘要比對、報價工時解讀——對外文書與數據解讀

B

B 級部門

主題清楚，關鍵資料或 OEM 授權／系統串接待補

B 級3 題 POC

修護管制／工程

B 級2 題 POC

B 級2 題 POC

B 級3 題 POC

B 級3 題 POC

製造本部

B 級2 題 POC

C 級部門

C 級1 題 POC

人事室
