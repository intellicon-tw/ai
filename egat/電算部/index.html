部門 電算部共 3 款 Agent POC理念 人機協作 · 非全自動

電算部這三題盤點得很扎實，都是 IT 團隊每天在做、量又大的重複性工作：IT 報修 Helpdesk 分流（每月 300-500 件）、AMOS 操作 FAQ 問答（全公司使用者、每月 200-400 次）、以及系統 Log 與資安事件摘要，場景、步驟、產出都寫得清楚，屬於馬上能開工的題型。亮點是這些知識來源多半是自有文件、不涉 OEM 授權，落地阻力低；資安摘要那題也已規劃好「先上傳匯出檔、中期再串 SIEM」的分階段路線，務實可行。要把 Agent 真正做出來，最該補的是真實資料：實際的歷史報修單匯出（含分類欄位、問題描述、處理方式）、IT FAQ 與系統清單、AMOS 內部操作手冊與教育訓練教材、以及系統 log／MDR 告警的實際匯出格式與嚴重度分級 SOP；有了這些，一線解法建議與分流準確度才立得住。以下每一頁對應一個需求，點進去可看到：需求與痛點 → 開發思路 → 完整提示詞 → 知識庫設計 → 建置流程 → 驗測情境。

IT 報修 Helpdesk 智慧分流助手

標準化作業

電算部服務台每月 300-500 件報修，每件人工分類與初步回覆約 10-20 分鐘，簡單問題重複詢問、複雜案件轉派資訊不齊常來回補件。

 #17

AMOS 操作 FAQ 問答助手

知識問答

全公司 AMOS 使用者每月 200 至 400 次重複詢問操作問題（工單、料件、採購、簽核怎麼點），每次 15 至 30 分鐘卡在等電算部 IT 或 key user 回覆，重複性高、佔用人力。

 #18

系統 Log 與資安事件摘要助理

數據解讀

資安／IT 人員每日花 1-2 小時人工翻閱跨來源系統 log 與 MDR 告警、比對分類、寫日報，重複且易漏判關聯事件（每月 20-30 次）。
