部門 無人載具部共 2 款 Agent POC理念 人機協作 · 非全自動

這個部門的盤點聚焦在無人載具事業最吃時間、也最關鍵的兩個環節：標案文件彙整與規格回應草稿、以及軍規／適航規範的符合性比對，兩題場景都很具體、輸入輸出清楚，開發思路已到位，是很好的深度示範起點。要真正把 Agent 做出來，最該補的是真實素材：實際招標文件與規格回應對照表範例、歷年投標文件版型、以及適用的軍用商規／無人機適航規範清單與設計測試文件；由於標案與軍規內容多屬機敏，建議走地端知識庫控管，並明確界定 OEM／規範的授權引用範圍。備妥這些，比對與草稿的準確度就能大幅拉高，而最終規格判定與投標核決仍由工程與業務團隊、主管把關。以下每一頁對應一個需求，點進去可看到：需求與痛點 → 開發思路 → 完整提示詞 → 知識庫設計 → 建置流程 → 驗測情境。
