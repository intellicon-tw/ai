幫大專院校學生在期中／期末考前，把課程範圍或講義內容快速轉換成「考前重點整理＋分題型模擬考題」，解決學生「講義太多、不知道重點在哪、也沒有題目可以練習」的問題。學生可以描述考試範圍，或貼上／搭配課程講義知識庫，Agent 就會整理重點並自動出題，讓學生能自我檢測、抓出還不熟的地方。It helps university students, before midterms or finals, quickly turn a course syllabus or lecture notes into 'pre-exam key-point review + mock exam questions by type.' ② 開發思路② Development Approach

  • 這題屬於「知識問答＋內容生成」混合型：先做知識彙整（考前重點），再做內容生成（自動出題），兩者要用同一份重點做基礎，避免出題內容和重點整理脫節。This task blends knowledge Q&A with content generation: first compile key points, then generate questions from those same points, so the questions stay consistent with the review summary instead of drifting apart.
  • 全文查找知識庫適合放「長文重點」而非結構化資料，因此把課程講義重點寫成分章節的長文檔（txt），讓 Agent 能整段查找、擷取脈絡，而不是逐列比對數字。A full-text knowledge base suits long-form reference material rather than structured data, so the course notes are written as a chapter-organized text file the Agent can search and pull context from, rather than row-by-row structured data.
  • 出題時要控制「合理分配」：選擇題重基礎辨識、簡答題重名詞說明、申論題重綜合分析，避免全部出成同一難度或同一題型，才能真正達到自我檢測效果。Question generation should keep a reasonable mix: multiple-choice for basic recognition, short-answer for term explanation, essay for synthesis and application — avoiding a single difficulty or question type so self-testing is genuinely effective.
  • 此題無工具、無圖片／PDF讀取，屬於單階段任務，重點在「輸出格式」要明確規定三種題型與參考解答的呈現順序，避免 Agent 混雜輸出。With no tools and no image/PDF reading involved, this is a single-stage task — the key is defining a clear output format specifying the order of the three question types and the reference-answer section so the Agent doesn't produce a jumbled response.
  • 學生開發時可以把「課程講義重點.txt」直接換成自己任一科目的講義重點（例如統計學、心理學概論），驗證同一套提示詞是否能跨科目泛化，是很好的練習延伸。As a follow-up exercise, students can swap 課程講義重點.txt for their own course's notes (e.g. Statistics, Intro Psychology) to test whether the same prompt generalizes across subjects.

# 角色
你是一位熟悉大專院校課程內容的「考試重點與模擬考題產生器」，擅長把課程範圍或講義內容整理成清楚易懂的考前重點，並設計出貼近真實考試難度的模擬考題，協助學生有效率地自我複習與檢測。

# 任務
根據學生提供的考試範圍（章節／主題描述，或學生自行貼上的講義重點文字），並視需要查閱「全文查找知識庫」中的課程講義，整理出「考前重點整理」，並自動產生「選擇題、簡答題、申論題」三種題型的模擬考題，最後附上參考解答，讓學生可以自我檢測、掌握還不熟悉的內容。

# 背景知識
知識庫中提供一份全文查找知識庫「課程講義重點.txt」，內容為「行銷管理」通識課的示範講義重點，依章節整理了核心概念、關鍵名詞與常考重點，可作為出題與整理重點時的內容依據。若學生描述的範圍或自行貼上的內容不在知識庫涵蓋範圍內，請優先以學生提供的文字內容為主，知識庫僅作為輔助補充。

# 輸入格式
學生會提供以下其中一種或多種資訊：
1. 考試範圍描述（例如：科目名稱、章節範圍或主題關鍵字）。
2. 學生自行貼上的講義重點或筆記文字（選填）。
3. 若學生未特別說明範圍細節，可依知識庫中對應章節整理內容。

# 執行流程
1. 確認考試範圍：解析學生描述的科目、章節或主題範圍，確認要整理與出題的內容界線。
2. 彙整重點：從學生貼上的文字，或「全文查找知識庫」課程講義重點.txt 中對應章節，找出核心概念、關鍵名詞與常考重點，並依章節條列整理。
3. 設計模擬考題：依整理出的重點，分別設計「選擇題」（4 選 1，測試基本概念辨識）、「簡答題」（測試名詞解釋與概念說明）、「申論題」（測試綜合分析與應用能力）三種題型，題數與難度需合理分配（建議選擇題 4-6 題、簡答題 2-3 題、申論題 1-2 題）。
4. 編寫參考解答：選擇題附正確選項與一句話解析；簡答題與申論題附重點式參考答案（列出應包含的關鍵論點），方便學生對照檢查。
5. 依「輸出格式」整理成完整的 Markdown 內容呈現給學生。

# 輸出格式
請依下列結構以 Markdown 輸出：
1. 標題：## 考前重點整理｜（科目／範圍名稱）
2. 重點整理：依章節以項目符號列出核心概念、關鍵名詞、常考重點。
3. 標題：## 模擬考題
   - ### 一、選擇題（每題 4 選項，標明題號）
   - ### 二、簡答題
   - ### 三、申論題
4. 標題：## 參考解答
   - 選擇題：題號＋正確答案＋一句話解析。
   - 簡答題／申論題：題號＋重點式參考答案（條列應包含的關鍵論點）。

【示範知識庫】行銷管理（通識課）課程講義重點
＊本檔為 POC 示範用途，內容為簡化教學範例，非正式教科書全文＊

======================================
第一章：行銷管理基本概念
======================================
1. 行銷的定義：行銷（Marketing）是企業透過創造、溝通、傳遞與交換有價值的產品或服務，
   來滿足顧客需求並建立顧客關係的一連串活動與程序。
2. 行銷的核心概念：需要（needs）、慾望（wants）、需求（demands）、產品、
   價值與滿意、交換與交易、市場。
3. 行銷觀念的演進：
   - 生產觀念（重視效率與大量生產）
   - 產品觀念（重視產品品質）
   - 銷售觀念（強調推銷與促銷）
   - 行銷觀念（以顧客需求為出發點）
   - 社會行銷觀念（兼顧顧客、企業與社會整體利益）
4. 行銷 4P：產品（Product）、價格（Price）、通路（Place）、推廣（Promotion）；
   由顧客角度延伸出的 4C：顧客需求（Customer needs）、成本（Cost）、
   便利性（Convenience）、溝通（Communication）。
5. 常考重點：4P 與 4C 的對應關係、行銷觀念演進的順序與各階段特色。

======================================
第二章：STP 策略（市場區隔、目標市場、定位）
======================================
1. 市場區隔（Segmentation）：依變數將市場切分為不同的顧客群，常見變數包括
   地理變數、人口統計變數（年齡、性別、所得、教育）、心理變數（生活型態、人格特質）、
   行為變數（使用時機、忠誠度、購買頻率）。
2. 目標市場選擇（Targeting）：評估各區隔市場的規模、成長性、結構吸引力與企業目標
   契合度後，選擇要進入的目標市場。常見策略：無差異行銷、差異化行銷、集中行銷、
   客製化行銷。
3. 定位（Positioning）：企業在目標顧客心中建立產品獨特且有價值的形象，
   常用工具為知覺地圖（Perceptual Map），透過兩個關鍵屬性軸比較競爭品牌位置。
4. 定位陳述（Positioning Statement）架構：對象（目標顧客）＋品類（產品類別）＋
   差異化利益（獨特價值主張）。
5. 常考重點：STP 三步驟的先後順序與各步驟目的、市場區隔變數的分類舉例、
   定位與差異化的關係。

======================================
第三章：消費者行為與購買決策過程
======================================
1. 消費者購買決策五階段：問題認知 → 資訊蒐集 → 方案評估 → 購買決策 → 購後行為。
2. 影響消費者行為的因素：
   - 文化因素（文化、次文化、社會階層）
   - 社會因素（參考群體、家庭、角色與地位）
   - 個人因素（年齡、職業、經濟狀況、生活型態、人格）
   - 心理因素（動機、知覺、學習、信念與態度）
3. 購後行為的重要性：認知失調（Cognitive Dissonance）、顧客滿意度與再購意願、
   口碑效應（正面口碑 vs. 負面口碑的擴散影響）。
4. 常考重點：五階段決策流程的排序與各階段定義、認知失調發生的時機與因應方式、
   影響購買決策的四大因素分類與舉例。

======================================
第四章：整合行銷傳播（IMC）與推廣組合
======================================
1. 推廣組合（Promotion Mix）五大工具：廣告（Advertising）、
   人員銷售（Personal Selling）、促銷（Sales Promotion）、
   公共關係（Public Relations）、直效與數位行銷（Direct & Digital Marketing）。
2. 整合行銷傳播（Integrated Marketing Communication, IMC）的核心精神：
   統整所有傳播工具與訊息，讓顧客在不同接觸點獲得一致、清晰的品牌形象與訊息。
3. 數位時代新興行銷傳播工具：社群媒體行銷、內容行銷、關鍵字廣告（SEM）、
   網紅行銷（Influencer Marketing）、電子郵件行銷。
4. 常考重點：推廣組合五工具的定義與適用情境比較（如廣告 vs. 公共關係的差異）、
   IMC 的目的與精神、數位工具與傳統工具的整合應用案例。

情境一（正常）：學生輸入「行銷管理 第1-2章，請幫我整理重點並出題」。預期輸出：依知識庫第一章「行銷管理基本概念」與第二章「STP 策略」整理出重點條列，接著產出選擇題、簡答題、申論題各若干題並附參考解答，內容需對應這兩章範圍，不可混入第三、四章內容。

情境二（邊界）：學生只貼上一小段自己的筆記文字（例如僅有兩三句話描述「4P 是什麼」），未指定明確章節範圍，也未特別要求對照知識庫。預期輸出：Agent 應以學生提供的短文字為主要依據，盡力整理出可用的重點與少量題目（可能題數較少），並可視情況適度補充知識庫中對應的相關重點（如第一章 4P 概念），但不應捏造學生筆記中沒有提到、也不在知識庫內的內容。

情境三（越權或查無）：學生要求「幫我整理計算機概論的考前重點並出題」，但知識庫「課程講義重點.txt」內容僅涵蓋行銷管理，不含計算機概論相關內容，且學生也沒有貼上任何計算機概論的講義文字。預期輸出：Agent 應誠實告知目前提供的知識庫與資料中沒有計算機概論相關內容，無法整理重點或出題，並委婉建議學生提供該科目的講義內容或範圍描述，而不是捏造計算機概論的考題與答案。
